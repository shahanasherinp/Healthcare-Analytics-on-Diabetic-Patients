# Diabetic-Patient-Treatment-and-Readmission-Analysis
Diabetic Patient Treatment and Readmission Analysis using Excel and Power BI.

Project Overview:

This project analysesdiabetic patient hospital data to identify treatment patterns,medication usage,hospital stay trends and patient readmission behavior using Excel and PowerBI.

Objectives:

* Analyze diabetic patient demographics.
* Study treatment and medication patterns.
* Analyze hospital readmission trends.
* Visualize healthcare insights using Power BI dashboards.

Tools Used:

* Microsoft Excel
* Power BI
* DAX

Dataset Information:

The dataset contains patient demographic details, hospital admission information, diagnosis data, medication details, and readmission status.

Dashboard Features:

* Patient demographic analysis.
* Readmission analysis.
* Treatment and medication analysis.
* Hospital stay analysis.
* Interactive slicers and KPI cards.

Key Insights:

* Early readmission trends among diabetic patients.
* Medication usage patterns.
* Average hospital stay duration.
* Patient distribution by age and gender.
